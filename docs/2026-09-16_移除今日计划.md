# 移除今日计划

## 已确认范围

用户没有逐日安排任务的需求，确认移除今日计划及关联入口。工作台保留当前状态、实际行动记录和各业务模块，不增加替代性的每日或每周计划。

## 实现

- 删除今日计划页面；旧 `/today` 地址（包括新增参数）跳转首页。
- 移除侧栏、快速新增、自媒体、开发、娱乐及历史咨询页面中的计划按钮。
- 首页移除今日完成率、已安排时长、时间线、待安排和备忘转计划；保留学习摘要、备忘、关注事项、模块摘要及其他快捷操作。
- 首页接口不再生成计划统计或计划逾期提醒；全局搜索不再返回历史计划。
- 移除仅供今日计划使用的每周起始日设置。历史设置值保留。
- 保留数据库、历史计划、每日复盘、备份、导出和后端兼容接口；回收站中的旧计划标为“历史计划记录”。不执行删除表或记录的数据迁移。

## 验收经验

首页精简后，大屏可能无需滚动。原有背景视差测试假定首页始终可滚动，导致断言失败；将滚动效果验证移到内容足够长的设置页，保留对实际滚动效果的检查。适用于删减页面内容后的布局回归，不应为满足旧测试而添加空白高度。

回归同时发现已有测试中的快速新增按钮名称与当前界面不一致，以及健身样例缺少现有循环训练要求的开始日期；仅同步测试名称与样例，未改这些业务逻辑。
