# 学习模块第一版

适用：UNNC EEE，按真实学习记录维护课程进度。本文件是学习模块唯一当前总文档，合并已确认需求与第一版实际范围，随代码提交。旧稿保存在 project005/docs/archive/learning，仅供追溯；与本文件冲突时以本文件为准。

## 使用

1. Chrome 登录 https://moodle.nottingham.ac.uk，在 My Modules 显示本学期课程。开启“查看 → 开发者 → 允许 Apple 事件中的 JavaScript”。必要时允许 macOS 自动化访问 Chrome。
2. 工作台“学习 → 导入课程 → 读取可见课程”，逐门选择本学期课程；也可粘贴学校课程页面地址。无需手填章节，不会下载课件。
3. 目录以 Moodle 原 section/主题为单位。首次导入需确认“已授课”，并取消不应复习的管理资料。当前不从课表推断进度。
4. 每个主题点“记录学习”：预习、复习或做题；整个主题完成或部分完成；页码、小节、理解反馈、分钟与备注。自测不是必做。未授课只记录预习；已授课的做题/复习完成才能增加复习覆盖。
5. “学习记录”支持补录实际日期和修改。重复保存同一条记录不会重复计数；再做一次复习会新增次数，但同主题覆盖只算一次。
6. “今天复习”提供最多三项短任务，受当日复习预算和已记录分钟约束。默认 60 分钟；预习另列，coursework 另计。本版不能自动估算作业负担。没有复习就不增加完成进度，不自动结转。
7. “同步目录”需要 Chrome 和有效 Moodle 登录。失效或网络错误提示重试，旧记录保留。新增主题待本人纳入；来源暂时缺失保留原主题，授课标记不被同步覆盖。

## 范围与限制

- 已实现：课程选择与目录导入、课件/作业页面链接、范围与授课标记、实际进度、部分完成位置、可选理解反馈、今日建议、记录修改、首页与今日计划摘要。
- 暂未实现：课件正文/公式/电路图分析、AI 自测题、课程日历、自动读取 coursework 截止时间、后台周期同步与通知、关机后手机推送。
- Moodle 目录解析适配当前常见 section/activity HTML；若学校改变结构，识别失败会提示，不用空目录覆盖已有内容。可见课程发现不代表所有课程；目标未出现时在 Chrome 打开 My Modules，或粘贴课程页面地址。
- 目录中自动识别的是主题与资源名，不宣称已经提取全部知识点。当前只有人工记录的理解情况，不把页数、耗时当成掌握程度。
- 间隔建议使用 1/3/7 天作为简单可解释起点，取决于困难/普通/独立反馈；不是科学证明的唯一周期，也不代表必做日期。旧稿中的研究参考保留在归档中，不作为第一版效果已经验证的证据。
- 断网可使用已保存的目录和个人记录；学校课件链接需学校网络和登录，链接不等于离线课件。
- 咨询入口、快捷操作、首页摘要及搜索结果移除；历史咨询数据库与备份保持可恢复。

## 验证方式

- `npm run verify`：lint、类型检查、单元/组件/集成、构建、生产产物和启动器测试。
- `npm run test:e2e`：所有页面回归及学习流程真实浏览器测试。macOS 可以设置 PLAYWRIGHT_EXECUTABLE_PATH 为已安装 Chrome 的可执行文件路径，无需额外下载浏览器。
- 学习测试覆盖：重复导入/提交、部分完成/预习计数、日期/时长校验、预算、登录失效不覆盖、重启、备份恢复、导出、三种主题与手机宽度。
- 自动测试使用明确标记的合成课程和独立测试数据库，不写入个人业务数据库，不代替真实 Moodle 登录后的完整导入验证。

## 已确认的产品规则

面向 UNNC EEE 大三，本学期由本人选择 4～5 门课程。已知总主题数、已授课主题数、已授课中已复习主题数与待加强数分开显示。主题覆盖是主要进度，不强制每个主题完成三轮考试。部分完成记录页码或小节，不按页数推断掌握比例；完成动作与理解程度分别记录，允许未评估。

每天额外复习默认最多 60 分钟，周末可手动调整；建议为当日 1～3 项，不强迫做完。无记录时进度不增不减，没有长期逐日排程、自动欠项结转或逾期扣分。重复复习增加次数但不重复增加覆盖，编辑原记录不会生成另一条。预习不自动转换成课后复习。

授课范围由本人确认；同步保留个人标记与记录。新主题先待纳入，来源缺失不删除原主题。第一版只读取目录及活动链接，不下载课件，不宣称解析正文、全部知识点或截止日期。
