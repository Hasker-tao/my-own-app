# 学习模块第一版（持续打磨）

适用：UNNC EEE，按真实学习记录维护课程进度。本文件是学习模块唯一当前总文档，合并已确认需求与第一版实际范围，随代码提交。旧稿保存在 project005/docs/archive/learning，仅供追溯；与本文件冲突时以本文件为准。

## 使用

1. Chrome 登录 https://moodle.nottingham.ac.uk，在 My Modules 显示本学期课程。开启“查看 → 开发者 → 允许 Apple 事件中的 JavaScript”。必要时允许 macOS 自动化访问 Chrome。
2. 工作台“学习 → 导入课程 → 读取可见课程”，勾选本学期多门课程后批量导入；也可粘贴学校课程页面地址。课程总览的环形图显示课件学习进度；进入课程后选一次“已学完到哪个主题”，该主题及之前主题的课件/资料链接计为已学。未确认位置时显示“—”。
3. 目录以 Moodle 原 section/Part 为单位。课件进度按纳入范围且仍在目录中的非 coursework、非测验资料项估算；同步出现新资料后分母会变化。管理资料可按 Part 取消纳入，不从 coursework 提交推断课件已学。
4. “复习”是考试前长期清单，按课程和 Part 折叠展示，不生成每日任务或时间预算。完整复习一个 Part 后计入考试复习进度；部分完成可记录页码或小节。
5. 每个 Part 可人工点亮一个重要星标，默认不点亮。重要程度与复习完成互相独立，并在 Moodle 重新同步后保留。
6. “学习记录”支持补录实际日期和修改。重复保存同一条记录不会重复计数；再做一次复习会新增次数，但同 Part 覆盖只算一次。
7. “Coursework 待办”区分未提交、已上传草稿、已正式提交和待核实，显示学校页面读到的截止文字、上传文件、最后修改、评分状态及成绩摘要。上传草稿不能当作正式提交。状态未识别但成绩已发布且有成绩值时，从待办移出，学校原始状态仍保留；其余不确定项可由本人确认完成或撤销，确认记录在本地并在同步后保留。
8. “同步目录”需要 Chrome 和有效 Moodle 登录。同步会读取课程目录、资料目录内的文件链接和 Moodle assignment 详情。工作台运行时每 30 分钟检查一次，也可手动同步；失败保留上次可靠数据。新资料、新 coursework，以及作业提交状态或截止信息变化显示为站内新消息。

## 范围与限制

- 已实现：多门课程选择与总览、课程目录与部分资料文件链接、coursework 提交/上传信息、站内新消息与待办、考试前复习清单、Part 折叠、重要星标、实际进度、部分完成位置、记录修改和首页摘要。
- 暂未实现：课件正文/公式/电路图分析、AI 自测题、课程日历、Moodle 以外平台的 coursework 状态、系统级或手机推送、关机后的检查。
- Moodle 目录解析适配当前常见 section/activity 和 assignment HTML；若学校改变结构，识别失败会提示，不用空目录覆盖已有内容。课程发现同时使用 My Courses 可见链接和 Moodle 自身只读课程列表接口，仍以账号实际权限为边界。
- 目录中自动识别的是 Part 与资源名，不宣称已经提取全部知识点。重要星标只代表本人判断的考试重要程度，不把页数、耗时或 coursework 提交当成掌握程度。
- 断网可使用已保存的目录和个人记录；学校课件链接需学校网络和登录，链接不等于离线课件。
- 咨询入口、快捷操作、首页摘要及搜索结果移除；历史咨询数据库与备份保持可恢复。

## 验证方式

- `npm run verify`：lint、类型检查、单元/组件/集成、构建、生产产物和启动器测试。
- `npm run test:e2e`：所有页面回归及学习流程真实浏览器测试。macOS 可以设置 PLAYWRIGHT_EXECUTABLE_PATH 为已安装 Chrome 的可执行文件路径，无需额外下载浏览器。
- 学习测试覆盖：重复导入/提交、部分完成/预习计数、日期/时长校验、预算、登录失效不覆盖、重启、备份恢复、导出、三种主题与手机宽度。
- 自动测试使用明确标记的合成课程和独立测试数据库，不写入个人业务数据库，不代替真实 Moodle 登录后的完整导入验证。

## 已确认的产品规则

面向 UNNC EEE 大三，本学期由本人选择 4～5 门课程。总览以一次确认的学习位置估算课件覆盖；考试前复习按纳入范围的 Part 独立统计。课件覆盖不代表复习完成；部分完成记录页码或小节，不按页数推断掌握比例。

复习页不安排每日任务、预算或自动欠项。无记录时进度不增不减；重复复习增加次数但不重复增加覆盖，编辑原记录不会生成另一条。每个 Part 的重要星标由本人设置，默认关闭。

同步保留个人范围、重要星标与记录。新主题先待纳入，来源缺失不删除原主题。第一版只读取目录及活动链接，不下载课件，不宣称解析正文、全部知识点或截止日期。

## 后续实用建议

下一步优先考虑考试范围模式：本人勾选考试涵盖的主题后，直接显示尚未覆盖和仍有困难的内容，不生成长期强制计划。其次是 coursework 手动补充入口，用于 Moodle 之外的平台或学校页面未暴露的截止时间，并明确区分“学校读取”和“本人补充”。错题本只有在能快速关联课程、主题和原题来源时才值得加入，避免变成新的录入负担。
