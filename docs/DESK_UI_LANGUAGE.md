# 桌面 App 风格与界面语言

第二种外观在设置页显示为“桌面 App”。持久化值仍为 `notebook`，以保持已有设置与 API 兼容；另外两种外观和明暗切换保持原有行为。

视觉系统以暖石色工作区、深石墨导航侧栏和铜色交互强调建立层次。深色模式使用暖炭色，不使用深蓝。模块图标单独存于 `public/assets/desk-icons/`，与 Liquid Glass 的模块图片区分；原有 Phosphor 交互图标系统继续使用。设计参考位于项目外层 `src/design-skills/`。

“数据与设置 → 界面语言”提供简体中文和 English。语言通过现有设置 API 保存，默认简体中文，不更改记录结构或业务接口。英文词表位于 `src/i18n/en.json`；`src/i18n.ts` 翻译界面文本、提示属性和日期显示，并在异步页面渲染后继续处理新增界面节点。个人记录本身不写回翻译结果。扩展界面文案时应补充词表并用浏览器检查实际渲染。

验证：lint、TypeScript 构建、自动化测试与 Playwright 中英文切换及九页文案检查。测试使用独立 `.test-data/e2e`，不会改动 `../../work/MuziWorkspace` 的真实业务数据。
